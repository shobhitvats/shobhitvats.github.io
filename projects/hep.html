TL;DR — Quick Summary

  • Connects C++ Geant4 physics engines directly to Blender's rendering viewport via HTTP/2 gRPC bidirectional streaming with CRC32 frame integrity checks.
  • Single-Mesh BMesh architecture consolidates 10,000+ particle track segments into one mesh object for 10–50x viewport speedups (30–60 FPS).
  • Encodes deposited step energy into vertex colour alpha to render dynamic Bragg Peak track thickness via Geometry Nodes.
  • Interactive state machine supports live Start, Pause, Step Event, and Stop controls from inside Blender.
