Overview — Velsera (Knowledge Base Verification & Validation)

  • Worked for nine months (May 2025 – Feb 2026, recognized through two internship extensions) with the Knowledge Base Verification & Validation (KB V&V) team at Velsera, Pune, under Senior Manager Dr. Gargi Nanda.
  • Delivered across two major components: data clean-up of orthogonal clinical curations and the independent design & development of a standalone Validator & Comparator Analysis application.
  • Engineered a modular two-stage Python workflow combining strict pre-comparison Gold Set standardization with a domain-aware multi-stage comparison engine (gene alias resolution, variant notation normalization, disease hierarchy matching, and drug canonicalization) alongside parallel JSON ingestion and local execution.
  • Incorporated feedback across 3+ rounds of User Acceptance Testing (UAT) covering file formats, reference libraries, and OS permissions; authored a comprehensive user manual and led live team demonstrations — achieving 100% daily adoption across KB V&V team members.

Problem & Regulated Validation Context

Clinical genomics knowledge-base verification requires checking curated Gold Set expectations — spanning genes, variants, disease indications, and therapies — against large volumes of structured JSON system outputs. When done manually in spreadsheets or via ad-hoc command-line scripts, formatting drift, biological synonyms, and technical barriers slow verification cycles and make cross-team adoption difficult.

After starting from high-level validation requirements and studying the clinical domain context, I built a self-contained desktop application capable of running locally within a regulated scientific environment so both technical and non-technical curation scientists could run high-throughput verification reliably.

Architecture & Core Contributions

Two-stage clinical data validation and multi-stage comparison engineered for daily team production

Orthogonal Curation Clean-Up

Audited and standardized orthogonal curation datasets prior to verification runs, resolving historical formatting inconsistencies and aligning records with official clinical reference tables.

Pre-Comparison Standardization Gate

Enforced strict row-level input validation across gene symbols, variant nomenclature, disease vocabularies, and approved drug lists — surfacing color-coded diagnostic summaries before costly comparisons run.

Domain-Aware Comparison Engine

Built multi-stage biological matching beyond literal string equality: resolving gene aliases and synonyms, normalizing protein/coding variant notations and fusions, evaluating parent–child disease ontology relationships, and canonicalizing core drug names.

Parallel Ingestion & Standalone Security

Implemented multi-core JSON loading and in-memory indexing inside a standalone executable application, processing large batches rapidly while keeping regulated validation files strictly local.

Explainable Pass/Fail Reporting

Generated structured Excel and summary outputs with explicit match-type classifications and granular failure-reason diagnostics so reviewers could pinpoint discrepancies without manual inspection.

Desktop GUI, UAT & Team Enablement

Paired the engine with an accessible graphical interface refined across 3+ rounds of User Acceptance Testing (UAT) for file-format, reference-library, and permission edge cases, backed by a complete user manual and live team demonstrations.
