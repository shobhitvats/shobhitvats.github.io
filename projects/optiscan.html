TL;DR — Quick Summary

  • Targets silent performance killers in Python (O(n²) string concatenation, N+1 I/O inside loops, repeated attribute lookups).
  • Built on LibCST (Concrete Syntax Tree) preserving comments and formatting for lossless diffs.
  • Three-Layer Filtering System (name heuristics, scope initialisation tracking, RHS type inference) cuts false positives from 100% (V1) to 0% (V3).
  • Multiprocessing via ProcessPoolExecutor analyses 120+ files/second with deterministic line metadata for AI agents.

Three-Layer Filter & Rule Catalog

Layer 1 — Name Heuristics

Filters 30+ counter patterns (cnt, total, idx) to avoid numeric false alarms.

Layer 2 — Init Tracking

Tracks first assignment in scope to distinguish integer accumulators from string builders.

Layer 3 — RHS Type Inference

Confirms string concatenation only when string literals, f-strings, or str() are observed.
