TL;DR — Quick Summary

  • Decomposes Python repositories into CodeChunk entities mapped as weighted directed dependency graphs.
  • Multi-pass AST NodeVisitor resolves aliased imports, inter-function calls, and data lineage.
  • Zero-Loss Rebuild Engine proves complete semantic extraction by reconstructing runnable codebases directly from graph nodes.
  • Supports function-, file-, and directory-level interactive physics visualisations via Pyvis (vis.js).

Architecture & V1 → V5 Milestones

Data Acquisition

Ingests remote Git repositories via GitPython or local directories with MD5 incremental hashing.

Semantic AST Engine

Three-pass visitor resolving aliased imports, call frequencies, and variable data links.

Pyvis Visualisation

Force-directed graphs exposing circular imports, god functions, and dead code islands.

Rebuild Proof Engine

Reconstructs original source files from extracted CodeChunk graphs with Black formatting.
