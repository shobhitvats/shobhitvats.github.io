TL;DR — Engineering Summary

  • Formalises classical astronomical rule systems into deterministic, verifiable modular Python pipelines.
  • Built on pyswisseph (Swiss Ephemeris C-Bridge) for sub-arcsecond planetary coordinate precision and Ayanamsa frame transformations.
  • Recursive Timing Engine subdivides a 120-year span into 5 nested temporal levels prorated from exact lunar coordinates.
  • Decoupled architecture supports 15+ analytical modules sharing standardised coordinate interfaces and SVG/3D Plotly visualisations.

Core Computational Subsystems

Recursive Timing (dasha_calc.py)

Quantitative Strength (shadbala_deep.py)

Stellar Geometry (kp_system.py)
